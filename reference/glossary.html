Glossary

Every lesson uses these terms the same way. New terms are added as lessons introduce them.

Alphanumeric
A letter or a digit. Python's c.isalnum() checks for this.
Anagram
A string with exactly the same letters as another, each the same number of times, possibly in a different order.
Average case
The typical cost of an operation, rather than its rare worst outcome. Dict lookups are O(1) on average.
Big O
A way to describe how cost grows as the input size, n, grows. O(n²) means that doubling n roughly quadruples the work.
Brute force
The direct approach that tries every possibility. It's a good starting point to state aloud before you improve on it.
Collision
When two different keys land in the same hash table bucket. Many collisions make lookups slower.
Complement
In Two Sum, the value that completes the target: target - x.
Constant space
O(1) space: memory use stays under a fixed limit however large the input gets. It doesn't mean only one item is stored.
Frequency count
A dict from each item to the number of times it appears.
Hash map
A structure that stores key-value pairs and finds a key quickly using a hash function. Python's version is dict.
Palindrome
A string that reads the same forwards and backwards, like "racecar".
Pointer
In this course, a variable holding an index into a list or string. It isn't a memory address, as it would be in C.
Scope
The part of a program where a name exists. In Python, a function creates a scope, but a for loop or an if block doesn't, so a loop variable still exists after its loop.
Seen map
This course's name for a hash map that records values from earlier in a single pass, so later steps can look them up.
Space-time trade-off
Using more memory to reduce running time, or the reverse.
Two pointers
A technique that keeps two indices and moves them by a rule, for example inward from both ends of a string.
