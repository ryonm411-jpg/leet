When to reach for it

You're comparing or swapping items from both ends of a list or string, and you'd like O(1) extra space. Layouts where both pointers start at the same end are covered in the Tech Interview Handbook's array guide.

The template: walk in from both ends

left = 0
right = len(s) - 1
while left < right:
    # use s[left] and s[right]
    left += 1
    right -= 1

Time O(n), space O(1). On an odd length, the pointers meet on the middle item. On an even length, they cross. Empty and one-item inputs skip the loop.

Valid Palindrome

def is_valid(s):
    left = 0
    right = len(s) - 1
    while left < right:
        if not s[left].isalnum():
            left += 1
        elif not s[right].isalnum():
            right -= 1
        elif s[left].lower() != s[right].lower():
            return False
        else:
            left += 1
            right -= 1
    return True

Each pass moves at least one pointer or returns, so there are at most n passes.

Two Sum II: sorted input

def two_sum_sorted(numbers, target):
    left = 0
    right = len(numbers) - 1
    while left < right:
        total = numbers[left] + numbers[right]
        if total == target:
            return [left + 1, right + 1]   # positions count from 1
        if total < target:
            left += 1     # left is too small even with the largest
        else:
            right -= 1    # right is too big even with the smallest

Each comparison rules out one number for good. Time O(n), space O(1), compared with O(n) space for a seen map. It relies on sorted input.
