Practice queue

LeetCode problems grouped by the patterns you know. Work from the top of each section, and tick each one when it's accepted without hints.

How to use it

  1. Set a 20-minute timer, or 35 minutes for a Medium. Before you type, name the pattern out loud.
  2. Trace one example by hand, then submit. A wrong answer is information, not failure.
  3. If time runs out, then watch the explanation. The NeetCode videos are good for this. Come back to the problem cold 2 or 3 days later.
