Online assessment checklist

For the Amazon SDE Intern OA. The format below comes from Amazon's invitation email. Anything it doesn't say is marked as unconfirmed.

Before the day

  • Find the exact deadline in the "SDE-I Online Assessment Invitation" email, and plan to finish at least a day early.
  • Check which languages the coding question and the repository question allow.
  • Do Amazon's coding assessment demo, so the editor is familiar before the timer starts.
  • Read the Leadership Principles.
  • Block 2.5 hours somewhere quiet, with a stable connection. The coding timer can't be paused.
  • No AI, notes or outside sites during the test. That includes this workspace.

Coding problem

StepDo
1Read it twice. Write two examples, including an edge case: one item, all equal, or the answer at the very end.
2Name the pattern: seen map, frequency count, two pointers or sliding window. If none fits, say the brute force.
3If no faster idea comes within about 10 minutes, code the brute force. A working answer beats an unfinished one.
4Trace one example by hand, then run.
5With time left, make it faster. Keep the working version in a comment.

Repository question

  1. Read the task and the README. Know what "done" means.
  2. Run the tests before changing anything.
  3. Read the failing test. It gives you the input, the expected result and what actually happened.
  4. Follow the calls with F12, Go to Definition. The bug is where a value first goes wrong, which is often not in the file the test names.
  5. Set a breakpoint, Debug Test, and look at the real values.
  6. Make the smallest change, then run every test. Never edit a test to make it pass.

Work Style Assessment

It explores how you approach work and make decisions. Third-party guides say it uses pairs of statements, which is unconfirmed. Answer honestly and consistently. Guessing what Amazon "wants" tends to make your answers contradict each other.
