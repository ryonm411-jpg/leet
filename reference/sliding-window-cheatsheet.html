When to reach for it

The problem asks about runs of items next to each other, such as "k in a row" or "any 5 consecutive days". Windows that grow and shrink are covered in the Tech Interview Handbook's array guide and come in a later lesson.

The template: fixed size k

def max_window_sum(nums, k):
    window = sum(nums[:k])          # the only full add-up
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]   # i enters, i - k leaves
        best = max(best, window)
    return best

Time O(n), space O(1), compared with O(n·k) for adding up every window from scratch.

Carry the best so far: Best Time to Buy and Sell Stock

def max_profit(prices):
    cheapest = prices[0]
    best = 0
    for price in prices:
        cheapest = min(cheapest, price)       # cheapest day up to now
        best = max(best, price - cheapest)    # sell today
    return best

Like a seen map, it carries what it needs from the left, but here that's a single number, so space is O(1).

Traps

TrapFix
Starting best = 0 when numbers can be negativeStart from the first real window, or from prices[0].
Removing nums[i - k - 1] or nums[i - 1]The leaving index is k places behind the entering one: i - k.
Using the overall lowest priceIt might come after the highest. Only a price from an earlier day counts.
