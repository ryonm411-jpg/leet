# Mission: Pass SWE Coding Interviews

## Why
Land a software engineering internship or new-grad job. Be ready for live coding rounds within 1-3 months (by about the end of January 2027).

## Near-term goal: Amazon SDE Intern online assessment
- Invitation received on 2026-11-05. There are 7 days to finish from receipt, so the deadline is about 2026-11-12. Aim to take it by 2026-11-11, leaving a day spare.
- Format, according to Amazon's recruiter email: one single-file coding problem, then a multi-file code repository question in a VS Code-style IDE with Run and Debug, then a Work Style Assessment tied to the Leadership Principles. About 2.5 hours in one sitting, and the coding timer can't be paused.
- Success: submit every section. Get a working answer on the coding problem, even a brute force. Finish the repository tickets. Answer the Work Style questions honestly and consistently.
- During OA week, add no new patterns. Practise under test conditions instead. After the OA, the NeetCode 150 list becomes the problem queue for the interview goal below.

## Success looks like
- Solve an unseen LeetCode Easy in Python in about 15-20 minutes, without looking anything up
- Make steady progress on Mediums by recognising which pattern applies
- State the time and space complexity of a solution and explain any trade-off
- Talk through the approach and test edge cases aloud, as in a real 30-45 minute interview
- Complete at least one mock interview with another person before applying

## Constraints
- Python is the interview language; basic Python is already comfortable
- Has tried a few LeetCode problems, but is still a beginner at interview problem solving
- 1-3 months available; daily study time not yet confirmed

## Out of scope
- System design interviews
- LeetCode Hard problems, for now
- Company-specific question lists, until the core patterns are solid
