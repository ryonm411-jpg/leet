The idea

A window is a run of items next to each other in a list, such as 3 numbers in a row. Many problems ask about every window of a fixed size k. The brute force adds up each window from scratch, which costs k steps for each of about n windows: O(n·k).

But neighbouring windows share almost everything. When the window slides one step right, one item enters on the right and one leaves on the left. Everything in the middle is unchanged.

In [2, 1, 5, 1, 3, 2], the window [2, 1, 5] sums to 8. It slides one step right, to [1, 5, 1]. What's the cheapest way to get the new sum?

With k = 3, the window covers indexes 2, 3 and 4. Index 5 now enters. Which index leaves?

Step through it with k = 3. Each window after the first costs two operations.

Best Window Sum

Given a list nums and a number k, where 1 ≤ k ≤ len(nums), return the largest sum of any k numbers in a row. So [2, 1, 5, 1, 3, 2] with k = 3 gives 9. It has to take O(n) time. The numbers can be negative.

Trace [2, 1, 5, 1, 3, 2] with k = 3 by hand before your first Run, writing down the window total and best after each step.

Stuck for 10 minutes? Show one solution 
def max_window_sum(nums, k):
    window = sum(nums[:k])
    best = window
    for i in range(k, len(nums)):
        window += nums[i] - nums[i - k]
        best = max(best, window)
    return best

Best Trade

prices[i] is a stock's price on day i. You buy on one day and sell on a later day. Return the largest profit, or 0 if no trade makes money. So [7, 1, 5, 3, 6, 4] gives 5: buy at 1, sell at 6. Trying every pair is O(n²). It has to be O(n) time and O(1) space.

This is the same move as the window: carry something forward instead of looking back. Try it before opening the hint.

Want a hint?

Walk the days left to right, and imagine selling on each one. The best day to have bought is the cheapest day before it. What one number do you need to keep updated as you go?

Trace [7, 1, 5, 3, 6, 4] by hand before your first Run. Then trace [2, 4, 1], whose answer is 2, because buying at 1 has no later day to sell on.

Stuck for 10 minutes? Show one solution 
def max_profit(prices):
    cheapest = prices[0]
    best = 0
    for price in prices:
        cheapest = min(cheapest, price)
        best = max(best, price - cheapest)
    return best
