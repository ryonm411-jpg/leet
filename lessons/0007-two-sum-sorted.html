Lesson 7 · Two pointers

Let the sum choose the pointer

About 30 minutes · Your win: solve Two Sum on sorted input in O(1) extra space, then tell which pattern a new problem needs

In Valid Palindrome, a matching pair moved both pointers inward. Here only one pointer moves at a time, and each sum tells you which one. Sorted order is what makes that safe.

Warm up

A list of n web requests, each with a status code from 100 to 599. Count the requests per status code. How much space does the dict use?

The idea

You get a list sorted from smallest to largest, and a target. Put left on the smallest number and right on the largest, then add them. Before reading on, use that to answer this one.

numbers = [1, 3, 8, 12]    target = 15
left is on 1, right is on 12, and 1 + 12 = 13

The sum is too small. What should you do next?

Your turn: Two Sum II

Given numbers, sorted from smallest to largest, and a target, return the positions of the two different elements that add up to target. Exactly one answer exists. Use O(1) extra space, so no dict.

This problem has a twist: positions count from 1, not 0. So [2, 7, 11, 15] with target 9 gives [1, 2].

Press Tab for each indent level, and read every line once before you run it. Last time, one read-through could have caught the missing not before the tests did.

Stuck for 10 minutes? Show one solution 
def two_sum_sorted(numbers, target):
    left = 0
    right = len(numbers) - 1
    while left < right:
        total = numbers[left] + numbers[right]
        if total == target:
            return [left + 1, right + 1]
        if total < target:
            left += 1
        else:
            right -= 1

A problem you haven't seen: Contains Duplicate

Now a change of pattern. Given a list of integers, return True if any value appears at least twice, and False if every value is different. The list isn't sorted, and it has to run in O(n) time on average. Work out which earlier pattern fits, then write it from memory.

Stuck for 10 minutes? Show one solution 
def contains_duplicate(nums):
    seen = {}
    for x in nums:
        if x in seen:
            return True
        seen[x] = True
    return False

A set is the tidier tool here, because no value is needed. We'll cover it when a later problem needs it.

Which pattern?

In an interview, nobody tells you the pattern, so noticing it is part of the job. Pick one for each problem before you think about code.

An unsorted list and a target. Return the original indices of two numbers that add up to the target.

A sorted list and a target, with O(1) extra space allowed. Does any pair add up to the target?

Two strings of lowercase letters. Can the first be rearranged, using all its letters, to make the second?
