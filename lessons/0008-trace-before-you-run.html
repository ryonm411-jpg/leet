Trace before you run

About 30 minutes · Your win: pass two new problems in at most two runs each, by checking one example by hand first

Last time you passed both problems, but it took 6 runs and 5. In a live interview, nobody runs tests for you, so you have to catch those bugs by reading your own code. Today's goal is fewer runs, not more speed.

The habit

Before each first Run, take the first example and walk through your code line by line, on paper or out loud. Write down the variables and what gets returned. Fix anything that disagrees with the expected answer, then run it. The Tech Interview Handbook's interview techniques suggest using your examples as test cases when you verify a solution. Tracing by hand is how you do that when nothing can run your code.

One piece of syntax to carry in: Python writes elif. The else if form from your last lesson is a SyntaxError here.

Cold problem: First Repeat

Given a list of integers, return the first value whose second appearance comes earliest as you read from the left. If nothing repeats, return None. So [2, 1, 3, 1, 2] gives 1, because the second 1 comes before the second 2. It has to take O(n) time on average. Trace that example by hand before your first Run.

Stuck for 10 minutes? Show one solution 
def first_repeat(nums):
    seen = {}
    for x in nums:
        if x in seen:
            return x
        seen[x] = True
    return None

Closest Sum

Given numbers, sorted from smallest to largest, with at least two elements, and a target, return the sum of two different elements that's closest to target. The tests never have a tie between two different sums. So [1, 3, 8, 12] with target 7 gives 9. Use two pointers and O(1) extra space. abs(x) gives the size of a number without its sign, so abs(total - target) is how far off a sum is.

Start with these two comments, filled in from your own reasoning, then trace [1, 3, 8, 12] with target 7 by hand before your first Run.

Stuck for 10 minutes? Show one solution 
def closest_sum(numbers, target):
    left = 0
    right = len(numbers) - 1
    best = numbers[left] + numbers[right]
    while left < right:
        total = numbers[left] + numbers[right]
        if abs(total - target) < abs(best - target):
            best = total
        if total < target:
            left += 1
        else:
            right -= 1
    return best
