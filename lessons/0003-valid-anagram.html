def repeat_gap(words):
    seen = {}  # word -> its index
    for i, word in enumerate(words):
        if word in seen:
            return i - seen[word]
        seen[word] = i
    return -1

The problem

Valid Anagram: given two strings, s and t, return True if t is an anagram of s. That means it has exactly the same letters, each the same number of times, possibly in a different order. Both strings hold lowercase English letters.

Someone suggests return set(s) == set(t). A set keeps each distinct letter once. Take s = "aab" and t = "abb". What does the function return, and does that match the correct answer?

The plan

This is Ransom Note with one extra rule. Count every letter in s, then walk through t and spend one letter each time. If a letter has none left, return False.

The extra rule is needed because Ransom Note allowed leftover magazine letters, while an anagram allows none.

Suppose you count s and spend t, with no other checks. Which input gets the wrong answer?

def is_anagram(s, t):
    if len(s) != len(t):
        return False
    counts = {}  # letter -> how many are left
    for c in s:
        counts[c] = counts.get(c, 0) + 1
    for c in t:
        if counts.get(c, 0) == 0:
            return False
        counts[c] -= 1
    return True
