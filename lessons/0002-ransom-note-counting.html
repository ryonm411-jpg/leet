def first_positions(words):
    first = {}
    for i, word in enumerate(words):
        if word not in first:
            first[word] = i
    return first

The problem

Ransom Note: given two strings, ransom_note and magazine, return True if you can build the note using letters cut from the magazine. Each magazine letter can be used only once. Both strings hold lowercase English letters, up to 100,000 of them.

Suppose you only check that each note letter appears somewhere in the magazine. What does that return for note "aa", magazine "ab", and is it right?

The idea: a frequency count

A frequency count is a dict from each item to the number of times it appears. Solve the problem in two passes:

  1. Count every letter in the magazine. This is your stock.
  2. Walk through the note and spend one letter each time. If the letter you need has none left, return False. If you reach the end, return True.

The syntax you need

There's one line to learn here, because a key has to exist before you can add to it:

counts = {}
counts["a"] += 1                     # KeyError: "a" isn't in the dict yet

counts["a"] = counts.get("a", 0) + 1 # works: a missing key counts as 0

d.get(key, default) returns the value for key, or default if the key is missing. It doesn't add the key to the dict.

def can_construct(ransom_note, magazine):
    counts = {}  # letter -> how many are left
    for c in magazine:
        counts[c] = counts.get(c, 0) + 1
    for c in ransom_note:
        if counts.get(c, 0) == 0:
            return False
        counts[c] -= 1
    return True
