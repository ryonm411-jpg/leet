In the OA you get one 100-minute timer for two problems, so wasted runs are wasted minutes. In this lesson, Run tests won't work until you've written a trace and ticked the read-through.

How the gate works

  1. Write your solution.
  2. Below it, as # comments, trace the visible example: at least 3 lines, one per loop step, with your variables' values. For example # i=1 c='w' left=0 best=2.
  3. Read your code top to bottom: every if/for ends in : and has an indented body, names aren't reused, there's a return at the end. Then tick the box.
  4. Press Run. The box unticks after every run, so read again before the next one.

Comments in Python are ignored when it runs, so your trace never breaks the code. Writing one in the OA editor is allowed and a good habit there too.

Warm-up: one name, one value at a time

You've missed this three times, always the same way: after a name is given a new value, you expect the old value to still be used. Step through it.

def total(prices):
    prices = 0
    for p in prices:
        prices += p
    return prices

total([4, 5])

The rule: Python looks a name up at the moment a line runs, and uses whatever the name points to right then. Use that rule on these two.

s = "abc"
t = s
s = "xyz"
print(t)

What does this print?

def f(nums):
    for n in nums:
        nums = [0]
    return nums

print(f([1, 2, 3]))

What does this print?

The safe habit: never assign to a parameter. Give every new value a new name: total, result, best.

Before every dict: "what's the key?"

In Isomorphic Strings your first dict was keyed by position (seen[indx] = c). The key is the thing you'll look up later. Ask: "When I come back to this dict, what will I have in hand?" That's the key. What you want back is the value.

Problem 1: Word Pattern

LeetCode 290, Easy. Paraphrased, because LeetCode blocks automated reading. Check the exact wording on LeetCode.

Given a pattern of letters and a string s of words separated by single spaces, return True if s follows the pattern: each letter always matches the same word, and no two letters match the same word. The number of words must equal the number of letters.

Examples: "abba", "dog cat cat dog" gives True. "abba", "dog dog dog dog" gives False, because a and b would both be dog.

You walk letters and words side by side. For the check "does this letter already have a different word?", what is the dict's key?

Stuck for 8 minutes? Show a hint

words = s.split(). If len(words) != len(pattern), return False straight away, because zip would silently stop at the shorter one. Then it's Isomorphic Strings with words: two dicts, check both, then store both.

Problem 2: Group Anagrams

LeetCode 49, Medium. Paraphrased. Check the exact wording on LeetCode.

Group the words in strs that are anagrams of each other (the same letters in any order). Return a list of groups. LeetCode accepts any order. Here the order of the groups doesn't matter either, but keep the words inside each group in the order they appear in strs. A dict of lists does that naturally.

Example: ["eat", "tea", "tan", "ate", "nat", "bat"] gives [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]].

One dict, with each value a list of words. What key makes all anagrams land on the same entry?

How much extra space does that dict use, for n words in total?

Stuck for 10 minutes? Show a hint

key = "".join(sorted(word)). If the key isn't in groups yet, set groups[key] = []. Then groups[key].append(word). At the end, return list(groups.values()).

New twist: a window that shrinks

Lesson 9's window had a fixed size. Some problems need a window that grows on the right and jumps its left edge forward when a rule breaks. Step through "longest stretch with no repeated character" on "pwwkew". The dict last maps each character to the last index where you saw it.

Problem 3: Longest Substring Without Repeating Characters

LeetCode 3, Medium. Paraphrased. Check the exact wording on LeetCode.

Return the length of the longest run of neighbouring characters in s with no character repeated. s can hold letters, digits, symbols and spaces, and can be empty.

Examples: "abcabcbb" gives 3 ("abc"). "bbbbb" gives 1. "pwwkew" gives 3 ("wke").

LeetCode says the characters are English letters, digits, symbols and spaces, so fewer than 128 possible characters. How much space does last use as s gets longer?

Stuck for 12 minutes? Show a hint

Keep last = {}, left = 0 and best = 0. Loop with for i, c in enumerate(s):. If c in last and last[c] >= left, set left = last[c] + 1. Then store last[c] = i and update best with i - left + 1. The >= left part matters: without it, "abba" moves left backwards at the last a.
