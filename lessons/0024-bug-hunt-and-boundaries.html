def is_valid(s):
    dict = {")": "(", "}": "{", "]": "["}
    stack = []
    for c in s:
        if stack and c in dict:
            if stack[-1] != dict[s]:
                return False
            stack.pop()
            continue
        elif c not in dict.values():
            return False
        stack.append(c)
    return True

def my_sqrt(x):
    lo, hi = 0, x
    while x and lo <= hi:
        mid = (lo+hi)//2
        if mid*mid == x:
            return mid
        elif mid*mid > x:
            hi=mid-1
        else:

Problem 1: Minimum Size Subarray Sum, cold

LeetCode 209, Medium. You did it in Lesson 22 with the hint. This is the spaced retry from a blank editor. Don't look back.

Given a list of positive ints nums and a positive int target, return the length of the shortest block of neighbours whose sum is at least target, or 0 if there's none. It must be O(n).

Examples: 7, [2, 3, 1, 2, 4, 3] gives 2. 4, [1, 4, 4] gives 1. 11, [1, 1, 1, 1, 1, 1, 1, 1] gives 0.

Stuck for 10 minutes? Show a hint

Never call sum on a slice inside the loop. Keep one running total. Add nums[right] as the window grows. While the total is big enough, record the length, then subtract nums[left] and move left on.

Problem 2: First Bad Version

LeetCode 278, Easy. Statement written from memory, as LeetCode blocks automated reading. Here is_bad is defined in the starter so the page can test it. On LeetCode it's called isBadVersion.

Versions 1 to n were released in order. Once a version is bad, every later one is bad too. Using only is_bad(v), find the first bad version, calling is_bad as few times as you can.

Examples: n = 5 with version 4 the first bad one gives 4 (False, False, False, True, True). n = 1, first bad 1, gives 1.

n can be 2,147,483,647. Which pattern fits best?

Stuck for 8 minutes? Show a hint

Same loop as Sqrt(x) in Lesson 23. lo, hi = 1, n. If is_bad(mid), save mid as the best so far and go left with hi = mid - 1. Otherwise go right with lo = mid + 1. Return the saved value. (Or notice that lo lands on it, as in Search Insert.)

Bonus: Product of Array Except Self, cold

LeetCode 238, Medium, from Lesson 22. A blank-editor retry.

Return a list where answer[i] is the product of every number except nums[i]. No division, O(n) time.

Examples: [1, 2, 3, 4] gives [24, 12, 8, 6]. [-1, 1, 0, -3, 3] gives [0, 0, 9, 0, 0].

Stuck for 10 minutes? Show a hint

answer[i] = (product of everything left of i) × (product of everything right of i). One pass from the left, then one from the right, each carrying a running product that starts at 1.
