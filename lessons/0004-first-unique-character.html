Stuck for 10 minutes? Show one solution 
def first_unique(s):
    counts = {}  # letter -> how many times it appears
    for c in s:
        counts[c] = counts.get(c, 0) + 1
    for i, c in enumerate(s):
        if counts[c] == 1:
            return i
    return -1

counts[c] is safe in the second loop, because every letter of s was counted in the first. If you open this, close it again and rewrite the function from memory.

A method for dict space

Last time you answered O(n) where the answer was O(1), then O(1) where it was O(n). Both answers are easy to give when you're looking at the length of the input or at the word "letters". Look at the key instead, and ask three questions:

  1. What is one key? A letter, a word, a number?
  2. How many different keys are possible?
  3. Does that number grow with the input? If there's a fixed limit, space is O(1). If more input can always bring new keys, space is O(n).
TaskOne keyPossible keysSpace
Count letters in lowercase stringsone letterat most 26, even for a billion charactersO(1)
Count words in a list of n wordsa whole wordno limit, and all n could differO(n)

Words are made of letters, but the key is the whole word, so the 26 doesn't apply. And O(1) doesn't mean one key: it means a limit that stays the same however long the input gets.
