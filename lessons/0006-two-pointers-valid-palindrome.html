The idea

A pointer here is just a variable holding an index. With two pointers, you keep two indices and move them according to a rule, which the Tech Interview Handbook's array guide lists among its core techniques. This lesson uses the most common layout: one pointer starts at each end, and they walk toward each other until they meet.

Here it is reversing a list, with no second list:

def reverse_list(items):
    left = 0
    right = len(items) - 1
    while left < right:
        items[left], items[right] = items[right], items[left]   # swap
        left += 1
        right -= 1

Each pass finishes one pair, so the loop runs about n/2 times, which is O(n) time. The only extra memory is two integers, however long the list is, so the space is O(1). Nothing needs doing when the pointers meet on a middle element, because it's already in place.

items = [1, 2, 3, 4]    # run reverse_list(items)

Your turn: a plain palindrome

A palindrome reads the same forwards and backwards, like "racecar". Write is_palindrome with two pointers. It's the same walk as above, but you compare instead of swapping. Decide what should happen when a pair doesn't match, and what an empty string should give.

Stuck for 5 minutes? Show one solution 
def is_palindrome(s):
    left = 0
    right = len(s) - 1
    while left < right:
        if s[left] != s[right]:
            return False
        left += 1
        right -= 1
    return True

A shorter version is return s == s[::-1], where s[::-1] builds a reversed copy of the string. How much extra space does it use?

The real problem: Valid Palindrome

Now some characters don't count. A character counts only if it's alphanumeric, meaning a letter or a digit, and uppercase and lowercase count as the same. So "A man, a plan, a canal: Panama" is a palindrome, and "race a car" isn't.

You need two new string methods:

  • c.isalnum() is True if c is a letter or digit.
  • c.lower() gives the lowercase version of c.

Step through the logic on "a,bA". A pointer on a character that doesn't count moves on without comparing anything.

Write it with two pointers, not by building a cleaned copy of the string, so the extra space stays O(1). The tests can't tell which you used, so that part's on you. Note the time you start.

Stuck for 10 minutes? Show one solution 
def is_valid(s):
    left = 0
    right = len(s) - 1
    while left < right:
        if not s[left].isalnum():
            left += 1
        elif not s[right].isalnum():
            right -= 1
        elif s[left].lower() != s[right].lower():
            return False
        else:
            left += 1
            right -= 1
    return True
