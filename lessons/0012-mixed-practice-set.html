Problem 1: Rising Streak

sales[i] is a shop's sales on day i. Return the length of the longest run of consecutive days where every day sold strictly more than the day before. A single day is a run of length 1. You can assume len(sales) ≥ 1.

Example: [3, 4, 5, 2, 6, 7, 8, 1] gives 4, from the days 2, 6, 7, 8.

Which approach fits best?

Stuck for 10 minutes? Show a hint

Keep two numbers: current, the streak ending today, and best. If today beats yesterday, the streak grows. Otherwise it restarts at 1. Update best on every day, not only when a streak breaks, or a streak that runs to the last day gets missed.

Problem 2: Top Seller

You're given a list of product IDs (strings), one per sale. Return the ID that sold the most. If several tie, return the one whose first sale came earliest in the list. The list isn't empty.

Example: ["pen", "cup", "cup", "pen", "ink"] gives "pen". Pen and cup both sold 2, and pen sold first.

Which approach fits best?

Stuck for 10 minutes? Show a hint

Since Python 3.7, a dict keeps keys in the order they were first inserted (Python docs). So when you loop over your counts, IDs come out in order of first sale. Replace the best only when a count is strictly greater, and an earlier ID wins any tie.

Problem 3: Exact Gap

amounts is a list of order amounts (integers) and d is a whole number, at least 1. Return True if any two orders at different positions differ by exactly d, and False otherwise.

Example: [10, 4, 7, 15] with d = 3 gives True, because 7 − 4 = 3.

Which approach fits best?

Stuck for 10 minutes? Show a hint

A smaller amount can come either before or after its partner. So for each x, check both x - d in seen and x + d in seen, and only then add x. Use in on a set, not .get.

Problem 4: Pairs Within Budget (stretch)

prices is sorted from low to high. Count the pairs of positions i < j where prices[i] + prices[j] ≤ budget.

Example: [1, 2, 3, 4, 5] with budget 6 gives 6: (1,2), (1,3), (1,4), (1,5), (2,3) and (2,4).

Which approach fits best?

Stuck for 10 minutes? Show a hint

Put left at the start and right at the end. If prices[left] + prices[right] fits the budget, then left also fits with every index between left + 1 and right, because those prices are smaller. That's right - left pairs at once, and then you move left. If it doesn't fit, move right.
