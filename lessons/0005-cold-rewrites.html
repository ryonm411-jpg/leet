Why the loop variable survives

You've chosen NameError in two lessons running, and that belief is correct in some languages. In Java, in C++, and in JavaScript with let, a variable declared in a loop's header disappears when the loop ends. The part of a program where a name exists is called its scope.

Python's rule is different: a for loop doesn't create a scope. It just assigns to a normal variable, again and again. So for x in [4, 7, 9] behaves much like this:

x = 4
# loop body runs
x = 7
# loop body runs
x = 9
# loop body runs
# loop over: nothing removes x

The same goes for if blocks. Of the structures you've used so far, only a function creates a scope.

Two Sum

Given a list of integers nums and an integer target, return the indices of the two different elements that add up to target, in any order. Exactly one answer exists. For example, [2, 7, 11, 15] with target 9 gives [0, 1]. It has to take O(n) time.

Stuck for 10 minutes? Show one solution 
def two_sum(nums, target):
    seen = {}  # number -> its index
    for i, x in enumerate(nums):
        complement = target - x
        if complement in seen:
            return [seen[complement], i]
        seen[x] = i

Ransom Note

Given two strings of lowercase letters, return True if ransom_note can be built from the letters of magazine, using each magazine letter at most once. Otherwise return False. For example, "aa" from "ab" gives False.

Stuck for 10 minutes? Show one solution 
def can_construct(ransom_note, magazine):
    counts = {}  # letter -> how many are left
    for c in magazine:
        counts[c] = counts.get(c, 0) + 1
    for c in ransom_note:
        if counts.get(c, 0) == 0:
            return False
        counts[c] -= 1
    return True
